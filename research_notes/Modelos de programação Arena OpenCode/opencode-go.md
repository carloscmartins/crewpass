# OpenCode Go models versus Arena programming rankings

## Which available OpenCode Go models and product characteristics are relevant to CrewPass coding?

### Takeaway
OpenCode Go presents itself as an agent-coding service and publishes model IDs, token prices, API routes, and plan-specific allowances, but does not publish model-by-model reliability measurements or a service-level uptime commitment. For this Django/Tailwind project, compare the Go catalog against Arena’s coding and agent results as evidence, not as a guarantee of Django, security, or repository-edit quality.

### Cited Findings
- OpenCode describes Go as access to popular open coding models, says the model set may change, and recommends using clients that send normal coding-agent traffic and a stable session identifier; it lists validated clients and also identifies some clients with incomplete session support. Go's validated-client language is about integrations, not a published per-model uptime SLA. — [OpenCode Go docs](https://opencode.ai/docs/go) (accessed 2026-11-06).
- Go docs publish the OpenCode model IDs and endpoint families. GPT 6 Luna routes through OpenAI Responses; Claude Haiku 5.5 through Anthropic Messages; GLM, Kimi, DeepSeek, and Kimi K2.7 Code through OpenAI-compatible chat completions; Qwen3.8 Max/Flash through Anthropic Messages. The docs state that the APIs are translated across endpoints. OpenCode model selection uses `opencode-go/<model-id>`. — [OpenCode Go docs](https://opencode.ai/docs/go) (accessed 2026-11-06).
- Current base prices in the official Go table (USD per million input/output tokens): GPT 6 Luna $0.10/$0.50 up to 272K tokens; Claude Haiku 5.5 $0.10/$0.50 up to 100K; GLM-5.3 $1.40/$4.40; GLM-5.3-Flash $0.15/$0.50; Kimi K3.1 Pro $2/$10; Kimi K2.7 Code $0.95/$4; Qwen3.8 Max $2/$6; Qwen3.8 Flash $0.15/$0.47; DeepSeek V4 Pro $0.66/$1.98 off-peak and $1.32/$3.96 at peak; MiniMax M3.1 Flash $0.15/$0.60. Cached-token rates and Go-plan allowance limits differ by model, so base input/output price alone is not the subscription’s total cost. — [OpenCode Go docs, token pricing and allowances](https://opencode.ai/docs/go) (accessed 2026-11-06).
- The directly queried session catalog (provided in the assignment, accessed 2026-11-06) reported these active IDs and effort variants: Luna and Haiku (low/medium/high/xhigh/max), GLM-5.3 and DeepSeek V4 Pro (low/high/max), Qwen3.8 Max (none/low/medium/xhigh), both flash models (varying effort options), Kimi K3.1 Pro (low/high/max), and Kimi K2.7 Code (no variants listed). It reported Luna’s 272K and Haiku’s 100K price tiers. This is session-supplied catalog evidence; the official Go docs are the public source of record and can change.
- The OpenCode Go docs describe stable global access and use “reliable” in their service positioning. They do not provide a public uptime history, per-model failure/latency figures, or a model-specific tool-call success guarantee. — [OpenCode Go docs](https://opencode.ai/docs/go) (accessed 2026-11-06).

### Inferences
- For repetitive work such as template edits, test scaffolding, or narrow fixes, a low-priced flash endpoint is an economical candidate, but neither price nor “Flash” in the name proves it is faster or more reliable. Measure on CrewPass tasks.
- Luna’s relatively large documented base-price context tier (272K) is useful for repository context; it does not itself demonstrate better long-horizon code editing. Haiku’s equivalent base price reaches a 5× higher price tier over 100K tokens, so large prompts need budgeting.
- As an OpenCode workflow, use documented effort variants deliberately: start with the default model on bounded tasks, raise effort for harder planning/debugging, and explicitly verify tool calls, diffs, tests, and migrations. This is a practical inference, not a vendor guarantee.

### Gaps
- No public, source-backed evidence found for model-specific availability/SLA, latency, tool-call reliability in OpenCode Go, or model-specific performance on Django 6, Python 3.12, SQLite migrations, tenant isolation, or pt-BR prompts.
- The Go pricing table changes over time and some rates/allowances depend on context length, cached tokens, or (DeepSeek) peak hours; re-check before making a lasting configuration choice.

## How do OpenCode Go catalog models map to Arena coding results?

### Takeaway
The most useful Arena comparisons are Code Arena: WebDev (blind human preference on real website/app builds, including multi-step/tool-using work) and Agent Arena: Code (observed coding-agent sessions). Luna, Haiku, GLM-5.3, and GLM-5.3-Flash have useful directly matching family/variant entries; Kimi K3.1 Pro was recently added to both WebDev and Agent Arena, but its exact overall WebDev row was not recoverable in this lookup. Arena scores do not measure CrewPass-specific backend/security correctness.

### Cited Findings
- Arena describes WebDev as front-end web-development tasks that include agentic coding workflows requiring multi-step reasoning and tool use; Code Arena also has an Image-to-WebDev leaderboard. Arena describes Agent Arena as dynamic real-agent-session rankings based on signals including task success, satisfaction, and steerability. Those are complementary measures, not controlled tests of OpenCode’s harness or Django repositories. — [Arena Code Arena](https://arena.ai/leaderboard/code); [Arena WebDev leaderboard](https://arena.ai/leaderboard/code/webdev); [Arena Agent leaderboard](https://arena.ai/leaderboard/agent) (accessed 2026-11-06).
- In the current WebDev ranking results indexed from Arena, GPT-6 Luna (Max) appeared at rank 34 with 1,581 ±7 and 12,332 comparisons; Claude Haiku 5.5 (High) at rank 30 with 1,587 ±20 and 978 comparisons; GLM-5.3 (Max) at rank 22 with 1,622 ±8 and 8,382 comparisons; GLM-5.3-Flash at rank 26 with 1,609 ±7 and 13,697 comparisons. The result snapshot also included Qwen3.8 Max / Qwen3.8 Max (0902) around ranks 11–12, at 1,672–1,674; Arena listed Qwen3.8 Flash-Next at rank 21 with 1,629 ±8. These are leaderboard entries/configurations, not assurances that the OpenCode Go endpoint is the same dated weights/version. — [Arena WebDev leaderboard](https://arena.ai/leaderboard/code/webdev) (accessed 2026-11-06; dynamic leaderboard).
- Arena Agent: Code results list GPT-6 Luna (Max) at rank 23 among the displayed entries, with task-signal values and 10,514 sessions; Arena’s Code Agent Pareto view reports +4.19% net improvement and median $0.13/task for that Luna configuration. The Pareto view lists Claude Haiku 5.5 (High) at +4.28% and $0.44/task. Arena’s task-cost figures are Arena-reported agent task costs and should not be equated with OpenCode Go token prices or monthly quotas. — [Arena Agent: Code leaderboard](https://arena.ai/leaderboard/agent/code); [Arena Code Agent Pareto](https://arena.ai/leaderboard/agent/code/pareto) (accessed 2026-11-06; dynamic leaderboard).
- Arena’s result page lists DeepSeek V4 Pro (High, 20260813) at WebDev rank 36 with 1,582 ±9 and 4,714 comparisons. It lists Kimi K2.7 Code at WebDev rank 70 with 1,474 ±9 and 4,962 comparisons. — [Arena WebDev leaderboard](https://arena.ai/leaderboard/code/webdev) (accessed 2026-11-06; dynamic leaderboard).
- Arena’s changelog lists Kimi K3.1 Pro (Max) as added to Code Arena: WebDev on Oct. 23, 2026 and Agent Arena on Oct. 24. The listing confirms availability on Arena, not its exact current rank or equivalence to the current OpenCode Go route. — [Arena leaderboard changelog](https://arena.ai/company/leaderboard-changelog) (Oct. 23–24, 2026; accessed 2026-11-06).
- Arena’s WebDev results show model revisions/efforts as separate entries: e.g. Qwen3.8 Max and Qwen3.8 Max (0902), and DeepSeek V4 Pro dated 20260813. OpenCode IDs such as `qwen3.8-flash` do not exactly match Arena’s `qwen3.8-flash-next`; exact provider-ID-to-Arena-row identity therefore cannot be assumed where revision suffixes differ. — [OpenCode Go model IDs](https://opencode.ai/docs/go); [Arena WebDev leaderboard](https://arena.ai/leaderboard/code/webdev) (accessed 2026-11-06).
- The official Arena changelog states Claude Haiku 5.5 (High) was added to Agent Arena on Oct. 14, 2026 and to Text Arena on Oct. 22. — [Arena leaderboard changelog](https://arena.ai/company/leaderboard-changelog) (accessed 2026-11-06).

### Inferences
- Within the Arena WebDev rows found, GLM-5.3 Max and Qwen3.8 Max have better measured app-building scores than Luna/Haiku, but at materially higher OpenCode Go token rates. Since Arena WebDev scores rank blind user preference, not bug-free backend changes, this is an escalation signal rather than a general coding-quality proof.
- Luna’s Arena Agent: Code result and token rate make it a reasonable value/default hypothesis; Haiku appears slightly better on the two observed Arena coding measures but with much lower WebDev sample count and a larger Arena cost/task. The result is not decisive enough to claim Haiku is categorically better.
- Kimi K3.1 Pro is a plausible high-complexity fallback to trial because Arena lists it in both coding and agentic leaderboards, but the retrieved evidence does not establish a specific rank advantage over Luna. Its $2/$10 Go price is 20× Luna on input and output respectively, so avoid sending routine edits there by default.
- Treat Arena rank as a screening input. For CrewPass, benchmark both recommendations against representative Django tasks: organization-scoped query fixes, `StaffMember`/`EventAssignment`/`Credential` changes, migration and test work, QR-token safety, and responsive template changes; review every diff and run the suite.

### Gaps
- Exact overall WebDev rank/score/sample count for Kimi K3.1 Pro was not available in the retrieved snippets; Arena’s announcement confirms it is listed but only gave a Code-category agent rank in its post. Arena pages blocked direct fetch (403), so the current figures were gathered from Arena search-indexed page content and should be rechecked interactively before publication/use.
- No Arena results matching the current OpenCode Go free entries Crouton Alpha Free, Iceman Contributor Free, or Beam Free were identified in the available search results; these are also marked limited-time by OpenCode, so no coding claim is made for them.
- No same-task, same-harness benchmark of the Go-served model IDs was found. Arena WebDev emphasizes front-end builds; Agent Arena’s sessions are not specifically OpenCode or CrewPass. No direct evidence was found for database safety, tenant isolation, migration quality, or Django/Python-specific task success.

## Which model pairing best fits ongoing CrewPass development in OpenCode?

### Takeaway
Recommended default: `opencode-go/gpt-6-luna` (start at medium/high effort, use max selectively). Pair it with `opencode-go/kimi-k3.1-pro` as the deliberate complex-task escalation model. This is a value-first, evidence-informed fit judgment—not a claim that Luna has the best raw coding score or that Kimi will always solve difficult changes better.

### Cited Findings
- Luna costs $0.10/$0.50 per 1M tokens within 272K context, and the session catalog showed a max effort option; Arena reported its max configuration at WebDev rank 34 (1,581 ±7, 12,332 comparisons) and Agent: Code rank 23, with $0.13 median Arena task cost. — [OpenCode Go docs](https://opencode.ai/docs/go); [Arena WebDev](https://arena.ai/leaderboard/code/webdev); [Arena Agent: Code](https://arena.ai/leaderboard/agent/code); [Arena Code Agent Pareto](https://arena.ai/leaderboard/agent/code/pareto) (accessed 2026-11-06).
- Kimi K3.1 Pro is listed in OpenCode Go at $2/$10 per 1M tokens with low/high/max options in the directly queried session catalog. Arena added its Max variant to WebDev Oct. 23 and Agent Arena Oct. 24. — [OpenCode Go docs](https://opencode.ai/docs/go); [Arena leaderboard changelog](https://arena.ai/company/leaderboard-changelog) (accessed 2026-11-06).
- A lower-cost alternative if Kimi proves wasteful is `opencode-go/claude-haiku-5-5`: official Go price equals Luna below 100K tokens ($0.10/$0.50), but rises to $0.50/$2.50 beyond 100K; Arena’s observed Haiku High WebDev result was rank 30 at 1,587 ±20 with 978 comparisons, and its Agent: Code Pareto entry was +4.28% / $0.44 per task. — [OpenCode Go docs](https://opencode.ai/docs/go); [Arena WebDev](https://arena.ai/leaderboard/code/webdev); [Arena Code Agent Pareto](https://arena.ai/leaderboard/agent/code/pareto) (accessed 2026-11-06).
- GLM-5.3 Max is another Arena-supported escalation candidate: rank 22, 1,622 ±8, 8,382 WebDev comparisons, at Go’s $1.40/$4.40 per million tokens. — [OpenCode Go docs](https://opencode.ai/docs/go); [Arena WebDev leaderboard](https://arena.ai/leaderboard/code/webdev) (accessed 2026-11-06).

### Inferences
- **Default Luna:** lowest-friction cost/context balance among the shortlist: its unit rate matches Haiku under 100K while retaining the 272K base-price tier; Arena has moderate WebDev preference but an Agent: Code result at very low observed Arena task cost. It suits everyday repo exploration, bounded implementation, tests, migrations, and reviews when paired with rigorous human/test verification.
- **Escalate to Kimi K3.1 Pro:** use for architecture decisions, multi-file secure tenant changes, subtle regressions, or when Luna has failed after a clear repair prompt. Its price is steep relative to Luna; use a targeted handoff with current files, constraints, failing tests, and requested acceptance checks rather than delegating the whole backlog.
- **Try Haiku before Kimi when context is under 100K and a near-cost fallback is desirable.** The Arena results are close and noisy; it is not proven uniformly stronger than Luna. For more substantiated WebDev performance (not necessarily backend correctness), GLM-5.3 is a cheaper-than-Kimi escalation candidate, but still costs far more than Luna.
- Practical OpenCode routing: Luna for standard implementation; Haiku as a small-context second opinion; Kimi K3.1 Pro or GLM-5.3 for a bounded complex task/review. Keep migrations, test execution, organization scoping, credential lifecycle invariants, and QR contents explicit in prompts and verify in code/tests. Do not give models operational authorization or accept access-control changes without independent review.

### Gaps
- No direct local evaluation was run against the CrewPass repository; preference may change with task shape, reasoning variant, context packing, harness/tool configuration, and region/provider load. The recommendation should be treated as an initial routing hypothesis and revised from actual task success, correction rate, latency, and Go allowance consumption.
- “Ongoing development” spans routine UI work and high-risk security/data-model changes. There is no single ranking that proves both; the proposed pair favors economy for routine work and quality headroom for harder work while keeping human review and automated tests as the acceptance gate.
